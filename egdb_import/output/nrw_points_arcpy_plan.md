## Calls

### 1. Create the database connection file

```python
arcpy.management.CreateDatabaseConnection(
    out_folder_path='build',
    out_name='egdb.sde',
    database_platform='POSTGRESQL',
    instance='127.0.0.1',
    account_authentication='DATABASE_AUTH',
    username='devsummit',
    password=<EGDB_PASSWORD>,
    save_user_pass='SAVE_USERNAME',
    database='devsummit',
    schema='#',
    version_type='TRANSACTIONAL',
)
```

`database` is required for PostgreSQL - unlike SQL Server, where it may be blank - and must be lowercase, because PostgreSQL folds unquoted identifiers and ArcGIS never quotes them. `SAVE_USERNAME` is not a convenience: ArcGIS Pro can hang opening a geodatabase from a connection file whose credentials were not saved. It is also why the resulting file goes to `build/` and is gitignored - it carries the credentials.

### 2. Create the feature class

```python
arcpy.management.CreateFeatureclass(
    out_path='build/egdb.sde',
    out_name='nrw_points',
    geometry_type='POINT',
    has_m='DISABLED',
    has_z='DISABLED',
    spatial_reference='arcpy.SpatialReference(4326)',
)
```

EPSG:4326, decided by: column names latitude/longitude: a geographic pair is decimal degrees, EPSG:4326. Note that 'decimal degrees' and 'EPSG:3857' are mutually exclusive - EPSG:3857 is metres. Creating a feature class through this tool registers it with the geodatabase, so the result is a real feature class rather than an unregistered table - which ArcGIS could only treat as a query layer, with a hand-supplied SRID and an ObjectID invented per session.
